Acceso Rápido y Ayuda

1. Co-Autorías N:M Al crear proyectos o publicaciones, puedes asociar a múltiples investigadores. Las relaciones se mantendrán sincronizadas en la base de datos automáticamente.
2. Creador APA Integrado En la pestaña de publicaciones, al presionar "Generar Cita APA", el sistema tomará automáticamente los autores seleccionados y creará la cita correspondiente.
3. Sostenibilidad Todos los elementos creados desde aquí se conectan bajo las tres líneas oficiales de investigación, manteniendo el orden metodológico del grupo.

Atajos de Investigador Científico

Utiliza estos accesos rápidos para cargar tus últimas investigaciones de forma ágil:
Registrar Nueva Publicación

Carga un nuevo artículo indexado en Scopus/Latindex y autogenera su cita bibliográfica estilo APA.

Registrar Nuevo Proyecto

Sube una propuesta de proyecto o registra el inicio de una investigación y asocia a tus coautores.
